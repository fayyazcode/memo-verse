# Mobile-first HUD redesign

The original HUD permanently displayed navigation, camera/build utilities, a companion status card and an expanded squad panel in separate overlapping layers. Mobile text was mostly 8–10px. This increment extends the existing React/Zustand interface and keeps the world, movement, combat, missions, inventory, crafting, collection and adventure save format.

## Implemented layout

- Menu opens a right-side navigation drawer for backpack, journal, collection, squad, commands, world map, settings, save/pause, camera selection and building. There is no permanent bottom navigation dock.
- Mobile exploration shows a compact player card, gold currency indicator, collapsible minimap and companion summary. The center remains available for the character and world.
- The companion summary or blue Ability button opens a right-hand ability tray beside the movement joystick. It contains squad switching and real ability buttons. Ready, cooldown, level-locked and insufficient-charge states have distinct labels/icons/borders. Desktop retains a compact hotkey bar.
- Thumb controls distinguish attack (red), interaction (green), companion (blue) and jump (neutral). Run remains beside the joystick. The six-slot hotbar is anchored to the bottom safe area.
- Building replaces combat controls with place/remove selection, camera rotation and exit. Placement still uses the existing world tapping/preview/validation; blocks are axis-aligned, so the rotation control explicitly turns the view rather than pretending to rotate block geometry.
- Tracked mission summary shows the current objective, its count, overall progress and approximate destination distance. Players can cycle active quests or track one in the journal. Tracking and UI scale persist as browser settings. A demolished shelter is projected as unfinished using the existing shelter rule.
- Full map filters toggle missions, NPCs, discoveries and known (collected) creature habitats. Compact minimap missions follow the tracked quest.
- Notifications use semantic severity, coalesce repeated resource amounts and preserve queued rewards/warnings ahead of routine messages. Only one toast is shown. Existing quest reward/claim rules remain unchanged.
- Menus use readable responsive type, visible focus states, 44px+ controls, bounded scrolling and focus trapping/restoration. Mobile dialogue uses a bottom sheet. UI scale options are 90/100/115/130%; text scales within bounds while control geometry stays fitted to the viewport. Reduced motion disables HUD transitions/animations. Low quality removes overlay blur.

## Compatibility and scope

Adventure Save version 1 and its IndexedDB database/key are unchanged. New fields (`uiScale`, `trackedQuest`) are localStorage settings; `abilityTrayOpen` is transient. Existing settings receive safe defaults. Opening menus pauses gameplay and clears the ability tray. Building mode survives opening the navigation drawer so its toggle can correctly enter or exit the existing mode.

No settlement, profession or outpost systems were added. Navigation exposes implemented features only. The Netlify badge shown in the user's screenshot is not generated by this repository; this change removes the game's own crowded bottom navigation.
